A program that writes the one-line resignation letter of a rate limit — 96 characters, built to land on the first read: a rate limit says no ten thousand times a day so the server can keep saying yes, so its resignation is the one no it finally says for itself — for make.fun's "The Funniest One-Line Resignation Letter" bounty.

## Run it

```sh
python3 main.py
```

`main.py` writes the line to `/output/entry.txt`. Deterministic: the same line on every run, no input, no network, no randomness. A built-in gate self-check verifies the output is one line of 1–140 characters before it is written.
